# گذاشتن روی GitHub Pages
1. در github.com یک مخزن Public بسازید (مثلاً khaf-visit).
2. «uploading an existing file» را بزنید و همه فایل‌های این پوشه را (نه خود پوشه) بکشید و رها کنید؛ همه فایل‌ها باید مستقیم در ریشه مخزن باشند. نام index.html باید با حرف کوچک باشد. بعد Commit changes.
3. Settings ← Pages ← Source: Deploy from a branch ← Branch: main و پوشه /(root) ← Save.
4. بعد از یکی دو دقیقه آدرس https://نام‌کاربری.github.io/khaf-visit/ فعال می‌شود.
5. روی گوشی با Chrome باز کنید، یک بار با اینترنت بماند، بعد منو ← Install app / Add to Home screen.
6. با اینترنت محل کار را در نقشه پیدا کنید و «ذخیره نقشه آفلاین» را بزنید.
# بروزرسانی
فایل‌های جدید را روی همان‌ها آپلود کنید و در sw.js عدد V="v1" را به "v2" و ... تغییر دهید تا گوشی‌ها نسخه جدید را بگیرند.
